# Window & door bid comparison

Static page comparing window/door bids opening by opening (required size and operation, each bidder's drawing, price, match status).

## Publish with GitHub Pages
1. Copy `index.html`, `img/` and `.nojekyll` to the repository root and push to `main`.
2. In the repository: Settings → Pages → Build and deployment → Source: "Deploy from a branch", Branch: `main`, folder `/ (root)` → Save.
3. The site appears at https://dmhenke.github.io/Remodel_WindowsDoors/ within a minute or two.

All data is embedded in `index.html`; there is no build step. Regenerated from `Window_Door_Bid_Comparison.xlsx` when bids change.
