# Window & door bid comparison

Static page comparing window/door bids opening by opening (required size and operation, each bidder's drawing, stated U-factor, price, match status).

## Publish with GitHub Pages
1. Copy `index.html`, `img/` and `.nojekyll` to the repository root and push to `main`.
2. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
3. Site: https://dmhenke.github.io/Remodel_WindowsDoors/

All data is embedded in `index.html`; there is no build step.
